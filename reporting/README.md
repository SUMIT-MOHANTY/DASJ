# Reporting Utility\n\nThis small utility generates the **Project Closure Report** for the Books Management project.\n\n## Usage\n```bash\npython reporting/scripts/generate_closure_report.py\n```\nThe markdown report will be written to `reports/ProjectClosureReport.md` and a PDF version to `reports/ProjectClosureReport.pdf`.\n\n## Dependencies\n- Python 3.11+\n- `markdown2`, `pdfkit`, `Jinja2` (see `requirements.txt`)\n- wkhtmltopdf must be installed in the host for `pdfkit` to work (Dockerfile installs it).\n
