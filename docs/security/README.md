# Security Scan Documentation\n\nThis folder contains the lightweight placeholder security‑scan implementation using OWASP ZAP (mocked).\n\n## How to run the real scan\n1. Replace `scripts/security/placeholder_zap_config.yaml` with a proper ZAP configuration.\n2. Install ZAP on the runner (or locally) and ensure `zap.sh` is on the PATH.\n3. Set the environment variable `STATIC_SITE_URL` to the URL of the deployed static site.\n4. Execute `scripts/security/run_scan.sh`. The raw findings will be written to `reports/security/raw_findings.json`.\n5. Run `python scripts/security/analyze_scan.py` to produce a summary and ticket stubs.\n\nThe GitHub Action workflow `.github/workflows/security-scan.yml` runs these steps automatically on each push to `main`.\n\n## Where to find reports\n- Raw findings: `reports/security/raw_findings.json`\n- Summary markdown: `reports/security/summary.md`\n- Placeholder remediation tickets: `reports/security/tickets/` (JSON files)\n
